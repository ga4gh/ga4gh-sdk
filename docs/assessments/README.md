# Dated engineering assessments

This directory keeps evidence snapshots that informed the living
[engineering principles](../engineering_principles.md). Each assessment names
its source revisions and the checks that produced its findings. Do not use an
assessment as a current defect list. Follow its linked issues for remediation
status, and reproduce a finding on the implementation base before fixing it.
